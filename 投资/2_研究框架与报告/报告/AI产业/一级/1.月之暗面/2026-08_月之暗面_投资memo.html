0. 一句话结论

不投：350 亿估值只看不买，≤150 亿美元且无治理恶化才谈（按 3x MOIC 门槛反推 [自定]），核心逻辑是 API 货币化被验证为真（ARR 5 个月 1→3 亿美元、占比 70%+、涨价不降量[C]），但 8 个月里估值膨胀 8.1 倍而 ARR 只涨 3 倍——倍数扩张贡献了涨幅的大头，当前价位隐含"再连续完美执行四年 + IPO 窗口不关"才勉强打平；最大风险是开源平权压价 + 地缘知产指控（白宫点名 K3）+ 未决仲裁三重折价没有被价格补偿。

投资性质：财务回报型（假想题；无产业协同可注入）。

⚠️ 证据声明：第 0 节建立在 A 级（阿里年报 8 亿美元/36%、智谱与 MiniMax 招股书数）与 B 级（官网定价/开源发布）上；ARR 轨迹为 C 级单源链（公司放风→媒体转述），在递表披露审计数与仲裁进展前，本结论为阶段性结论（待补证据见 9.5）。

数据口径：估值时间线（亿美元，对数轴）。2024-02 的 25 亿与阿里 8 亿/36%（FY2024 年报，A 级）互洽；2025-12 至 2026-08 各轮为媒体多源一致 [C]；500 亿为 G 轮传闻 [C]，空心点标记。检索日 2026-08-07/08。

2. 产品与技术：落地真相

  • 生产环境真实使用：OpenRouter token 用量榜首（K2.5 领衔）+ K3 开源"开发者热情远超预期" [C]；SimilarWeb 月访问约 3,300 万 [C]——生产调用量，不是 benchmark 刷分。
  • 工程能力：GTC 2026 主会场演讲 + K2.5 技术路线完整披露 [C]；K3 为 2.8 万亿参数、原生多模态、100 万 token 上下文，2026-07-27 全量权重开源（全球参数最大开源模型）[B]。
  • 三本账：K3 定价输入 ¥20/输出 ¥100 每百万 token（≈$3/$15），缓存命中 $0.30 [B 官网]；较 K2.6 提价 2.1 倍仍放量 [C]——毛利未披露，但"涨价不降量"说明定价权为真。
  • 标准产品 vs 定制：几乎全标准品（API/订阅），无交付包袱——与智谱（政企项目制，毛利率 50%+ 但重交付 [A 招股书]）的模式分野。
  • 壁垒在哪一层：时间差 + 开发者心智（开源分发）。"OpenRouter 默认选项"的位置有自增强性（工具链适配→教程→再适配）。
  • 基础模型升级对它＝加深护城河——它自己就是基础模型；风险在同级开源竞品而非上游。
本节判断：产品是［真落地］，壁垒［时间差］（领先窗口约 6-12 个月，需代代续上）（证据等级：B/C）｜方向：[支持投资] ｜ 触发依据：OpenRouter 登顶 + 提价 2.1 倍不降量。
