# 投研工作台（公开版）

个人投资研究体系的静态展示站点：10 个标的的分析报告与投资 memo、判断追踪台账与验证日历、研究方法论与取数链路。

## 请先读

- 全部内容仅使用公开信息（上市公司定期报告与公告、交易所与监管披露、公开行情数据、工商与招投标公开记录），不含任何非公开信息。
- 内容为个人研究记录与方法论练习，**不构成投资建议、证券分析报告或任何买卖推荐**，不代表任何雇主或机构的立场。
- 部分标的因涉及在职公司及其关联方，按合规要求不在公开版展示，因此台账编号不连续。
- 年报原件（PDF）与交易所公告页属第三方版权材料，未随本站发布；取数底稿、中间产物与分析脚本已完整保留。
- 数据截止时点见站内各篇标注，没有后续更新义务。

## 本目录的生成方式

由本地仓库执行 `python3 tools/build_publish.py` 自动构建，构建时会做敏感内容摘除、链接完整性校验与发布前残留扫描；请勿直接手改本目录。
